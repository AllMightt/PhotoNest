# PhotoNest-WeChetMini

PhotoNest 客户端原生微信小程序。

## 开发方式

用微信开发者工具直接打开本目录：

```text
/Users/lucky_sun/Desktop/PhotoNest/PhotoNest-WeChetMini
```

本地调试时需要在微信开发者工具中勾选“不校验合法域名、web-view、TLS 版本以及 HTTPS 证书”。

默认后端网关：

```text
http://localhost:8080
```

推荐启动参数：

```text
pages/guest/home/index?shareCode=pn_test_001
```
